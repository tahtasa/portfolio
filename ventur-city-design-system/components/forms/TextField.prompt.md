Text input with optional 12px label — use for any free-text form entry.

```jsx
<TextField label="Email" placeholder="you@example.com" />
<TextField theme="dark" placeholder="Search" />
```

States: default, focus (2px green.100 border), placeholder (black.0 light / black.20 dark), disabled (green.15 / black.50 fill, black.10 text). Height 44, radius 8, 16px side padding.
