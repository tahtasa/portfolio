Square icon-only button — use for toolbar/back/close actions where a label would be redundant.

```jsx
<IconButton variant="secondary" label="Back"><Icon name="chevron-left" size={20} /></IconButton>
```

Sizes sm/md/lg = 24/40/54px. Variants: tertiary (green.5, default), secondary (slate), primary (lime), ghost. Icon ~50% of box.
